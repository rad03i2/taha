# حسابات المولدة

تطبيق أندرويد لإدارة حسابات المولدة الكهربائية: المشتركون، الأمبيرات، التسديد الشهري، الديون، الملاحظات.

- الواجهة: HTML/CSS/JS بدون أدوات بناء (`www/`) داخل Capacitor.
- البيانات محلية (IndexedDB) وجاهزة للمزامنة السحابية لاحقاً (معرّفات uuid، وقت التعديل، حذف ناعم).
- الـ APK يُبنى تلقائياً عبر GitHub Actions ويُنشر في Releases.

## الحسابات والمزامنة
1. أنشئ مشروع Supabase والصق `supabase/schema.sql` في SQL Editor ثم Run.
2. ضع `SUPABASE_URL` و`SUPABASE_KEY` (anon) في `www/js/config.js`.
3. من التطبيق (جهاز المدير): «أنا المدير وأريد إنشاء المساحة» ثم من «المزيد ← إدارة المشرفين» أنشئ حسابات المشرفين.
